# Warehouse REST API

REST API для управления товарами на складе.

## Технологии

- Python 3.12
- FastAPI
- PostgreSQL 16
- Docker Compose

## Возможности

- Создание товара
- Получение списка товаров
- Получение товара по ID
- Обновление товара
- Удаление товара
- Проверка входных данных и уникальности SKU

## Модель товара

| Поле | Тип | Ограничения |
|---|---|---|
| id | integer | Первичный ключ, автоинкремент |
| title | string | Не пустое |
| sku | string | Уникальное, не пустое |
| quantity | integer | Не меньше 0 |
| price | decimal | Больше 0 |
